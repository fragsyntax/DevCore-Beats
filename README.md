# DevCore Beats — New From Scratch

1. Open `config.js` and replace `PASTE_YOUTUBE_DATA_API_V3_KEY_HERE` with your YouTube Data API v3 key.
2. Upload the five files to GitHub.
3. Enable GitHub Pages in repository Settings → Pages.
4. Search for a song.

Features: YouTube search, automatic covers, play/pause, previous/next, seek, volume, mute, mobile UI, official YouTube IFrame playback.
