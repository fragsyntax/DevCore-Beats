# 🎧 DevCore Beats — Final

Spotify-inspired music discovery website using the supplied DevCore Beats and DevCore Studio logos.

**Powered by DevCore Studio and Dream Wave Production**  
**Made by Fragsyntax**

## Playback
- YouTube Data API v3 search + official YouTube IFrame Player
- Spotify official Embed
- SoundCloud official Widget
- No downloading or bypassing protected audio

## Setup
1. Open `config.js`.
2. Replace `PASTE_YOUTUBE_DATA_API_V3_KEY_HERE` with your YouTube Data API v3 key.
3. Upload the project contents to a GitHub repository.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → `main` → root.

## Song cover, title & singer
YouTube search results now show the official YouTube thumbnail, song title and channel/singer name. Selecting a result updates the main DevCore Beats player with that cover image, title and singer automatically.

## Language categories
The homepage now includes **Punjabi, Haryanvi, Bhojpuri and Hindi** tabs, each with **Top 50** and **Latest Songs** sections. With a YouTube API key, these sections automatically search YouTube and show official thumbnails, song titles and singer/channel names. Without a key, demo cards are shown instead.
